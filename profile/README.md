Infrastructure and tooling by [@alyraffauf](https://github.com/alyraffauf).
Built with NixOS, Kubernetes, and a fondness for pocket monsters. ❤️

- [sinnoh](https://github.com/devon-systems/sinnoh): public-facing production infrastructure for websites and applications, including client work.
- [johto](https://github.com/devon-systems/johto): a hybrid cloud for self-hosted services, media, storage, and remote builds.
- [hoenn](https://github.com/devon-systems/hoenn): Nix configurations for personal machines and home infrastructure across Linux and macOS.
- [infra](https://github.com/devon-systems/infra): shared Backblaze B2 storage, Tailscale policy, maintenance tools, and operations guides.
- [dvnpkgs](https://github.com/devon-systems/dvnpkgs): custom nix package set with pinned versions, forks, and packages not yet in upstream nixpkgs.
